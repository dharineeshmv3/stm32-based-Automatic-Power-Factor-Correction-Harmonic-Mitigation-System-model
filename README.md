# STM32-Based Automatic Power Factor Correction & Harmonic Mitigation System

## Overview
This project focuses on the design and development of an STM32-based Automatic Power Factor Correction (APFC) and Harmonic Mitigation System. The system aims to improve power quality by addressing poor power factor and harmonic distortion in electrical systems.

## Key Objectives
- Improve power factor through automatic reactive power compensation.
- Reduce harmonic distortion and improve power quality.
- Implement embedded control using an STM32 microcontroller.
- Enhance electrical system efficiency and reliability.

## Technologies
- **Microcontroller:** STM32
- **Domain:** Embedded Systems & Power Systems
- **Focus:** Power Factor Correction and Harmonic Mitigation
